CacheGuard

Watch cache eviction policies decide, one request at a time. A desktop simulator for LRU, LFU, FIFO, MRU and Random replacement, built with Java 17 and Swing.

Download the jar View source

What you can do

Step through requests

Pick a policy and 2–16 blocks, enter a request sequence, then step forward or run all. Hits, misses and evictions show up on the blocks as they happen.

Compare all five policies

Replay one identical stream, even millions of requests, through every policy in parallel and compare hits, misses, ratios and evictions.

See the trends

Every finished run is saved. Statistics shows average hit ratio per policy and how your sessions have changed over time.

Keep your data

Settings and history are stored as JSON and can be exported and imported. Dark and light themes included.

The policies

PolicyEvictsData structure
LRUThe block unused for the longest timeHashMap + doubly linked list
LFUThe block with the fewest accesses (ties: least recent)HashMap + frequency buckets
FIFOThe oldest resident blockArrayDeque + HashSet
MRUThe most recently used blockHashMap + doubly linked list
RandomA random block (seeded, repeatable)ArrayList + index map

Run it

You need Java 17 or newer.

java -jar cacheguard-1.0.0.jar

Or build from source with Maven:

git clone https://github.com/YOUR_USERNAME/cacheguard.git
cd cacheguard
mvn package
java -jar target/cacheguard-1.0.0.jar
